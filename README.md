# BeaconCraft
Welcome to BeaconCraft.
We are a lightweight Offline Minecraft Launcher fully made in Python!
With this clean ui you can start Minecraft very EASILY.
We do NOT track our users and it's completely safe.

# Max Supported Version
1.21.11, anything above that has a high chance of crashing.
Use 1.21.11 or below.
I am working on a fix.
